A Flask-based machine learning platform that classifies Kinyarwanda text into Hate, Sarcasm/Joke, or Normal using a trained Logistic Regression model. Features include email verification, user/moderator roles, prediction explanations (highlighting top influential words), individual analysis history, flagged content monitoring, moderator export tools, rate limiting, and a clean UI. Also includes an extension tool for quick predictions.
